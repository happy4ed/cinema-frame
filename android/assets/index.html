제외한 영화

제외한 곡
지금 재생의 「재즈에서 빼기」처럼 음악 장르에서 뺀 곡이에요. 그 장르를 고를 때만 빠져요.
API 키
새 OST 를 찾을 때 쓰는 키예요. Gemini · Last.fm · TMDB 개발자 페이지에서 받은 키를 넣어요. 키는 액자에만 저장되고, 바꿀 키만 넣으면 돼요.
